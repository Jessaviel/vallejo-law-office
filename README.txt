VALLEJO LAW OFFICE — FREE WEBSITE STARTER
Version: 1.0

IMPORTANT
This folder contains a website preview, not a live website. The form is a local demo only:
- It does not send requests to the law office.
- It does not save submissions.
- It does not have staff login.
- It does not upload or store files.
Do not enter real client information or upload legal documents.

WHAT I PREPARED
- index.html: maroon-and-gold responsive website preview.
- supabase/schema.sql: starter database schema for a later secure setup.
- DEPLOY_GUIDE_BISAYA.txt: beginner-friendly next steps.

SAFEST FREE APPROACH
1. Publish only the public informational page first using a free static hosting plan.
2. Before collecting any real client data, set up and test a database, staff authentication, private storage, access rules, backups, and privacy notice.
3. Keep client uploads disabled until security policies are tested by a competent person.
4. Do not put private keys, passwords, or service-role keys into website files.
5. A free plan can have limits, pauses, or change its terms.

This is a starting point. It is not legal, security, or data-privacy compliance certification.
